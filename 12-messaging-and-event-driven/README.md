# Messaging and Event-Driven Systems

This module focuses on asynchronous communication and event-driven design.

Topics covered:
- Queues vs pub/sub vs streams.
- Delivery semantics: at-most-once, at-least-once, exactly-once.
- Message ordering and partitioning.
- Schema evolution and message contracts.
- Dead-letter queues, retries, and backoff.
- Outbox and inbox patterns.
- Event sourcing vs event-driven architectures.
- Backpressure and consumer scaling.
