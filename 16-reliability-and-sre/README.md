# Reliability and SRE

This module teaches how to keep systems reliable under real-world load and
failure.

Topics covered:
- Reliability principles and error budgets.
- Capacity planning and load forecasting.
- Resilience patterns: circuit breakers, bulkheads, retries.
- Rate limiting and graceful degradation.
- Incident response and runbooks.
- Postmortems and root cause analysis.
- Chaos engineering fundamentals.
- High availability and disaster recovery.
