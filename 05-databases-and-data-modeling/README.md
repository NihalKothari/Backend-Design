# Databases and Data Modeling

This module focuses on choosing and designing data storage for backend
applications.

Topics covered:
- Relational vs NoSQL database families and use cases.
- Entity-relationship modeling, normalization, denormalization.
- SQL fundamentals, joins, and query patterns.
- Index types, query plans, and performance tuning.
- Transactions, ACID properties, isolation levels.
- Schema migrations and versioning strategies.
- Replication, sharding, and partitioning approaches.
- Consistency, availability, and durability tradeoffs.
- Backups, restore, and disaster recovery planning.
- ORMs, query builders, and migration tooling.
