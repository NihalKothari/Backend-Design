# Networking and HTTP

This module covers how data moves over networks and the web protocols used by
backend systems.

Topics covered:
- OSI/TCP/IP layers and how packets move through the stack.
- IP addressing, subnetting, routing basics.
- DNS resolution and caching.
- TCP vs UDP, handshakes, congestion control, MTU.
- TLS fundamentals and certificate handling.
- HTTP methods, status codes, headers, cookies.
- HTTP/1.1 vs HTTP/2 vs HTTP/3, WebSockets.
- REST vs RPC, gRPC basics.
- Load balancers, reverse proxies, CDNs.
- Latency, throughput, retries, timeouts, backoff.
