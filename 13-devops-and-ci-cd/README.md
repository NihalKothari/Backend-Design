# DevOps and CI/CD

This module covers delivery pipelines and operational automation.

Topics covered:
- CI pipelines: build, test, lint, and quality gates.
- CD pipelines and approvals.
- Artifact repositories and versioning.
- Infrastructure as code (IaC) basics.
- Containers and registries.
- Deployment strategies: rolling, blue/green, canary.
- Configuration and secrets management.
- Feature flags and release management.
- Environment parity and staging practices.
