# DevOps and CI/CD

This module covers delivery pipelines and operational automation. Each
subtopic includes key concepts, a real-world example, and a diagram.

## Progression expectations

| Level | Outcomes |
| --- | --- |
| Beginner | Set up basic CI pipelines for build and test. |
| Intermediate | Build containers and manage environments. |
| Senior | Choose deployment strategies and IaC practices. |
| Principal | Define CI/CD standards, quality gates, and policies. |

## How to use this module
- Start with CI and CD basics.
- Create a pipeline or checklist per subtopic.
