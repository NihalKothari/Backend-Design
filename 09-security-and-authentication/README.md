# Security and Authentication

This module covers security fundamentals and protection strategies. Each
subtopic includes key concepts, a real-world example, and a diagram.

## Progression expectations

| Level | Outcomes |
| --- | --- |
| Beginner | Learn OWASP risks and input validation basics. |
| Intermediate | Implement auth flows, hashing, and secrets handling. |
| Senior | Lead threat modeling and choose authorization models. |
| Principal | Define security baselines and compliance requirements. |

## How to use this module
- Start with security principles and threat modeling.
- Create a checklist or diagram for each subtopic.
- Tie topics to real security incidents or audits.
