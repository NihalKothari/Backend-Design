# Security and Authentication

This module covers security fundamentals and how to protect backend systems.

Topics covered:
- Security principles: least privilege, defense in depth.
- Threat modeling and risk assessment basics.
- Password hashing, storage, and MFA.
- Session-based auth, token-based auth, JWT.
- OAuth2/OIDC flows and delegated authorization.
- Authorization models: RBAC and ABAC.
- Input validation and output encoding.
- OWASP risks: XSS, CSRF, SQLi, SSRF.
- Secrets management, encryption, key rotation.
- Audit logging and security monitoring.
