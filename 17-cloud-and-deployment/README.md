# Cloud and Deployment

This module covers deploying services on cloud platforms and managing
infrastructure.

Topics covered:
- Cloud primitives: compute, storage, networking.
- Managed databases and caches.
- Autoscaling and load balancing.
- Containers and Kubernetes basics.
- Serverless functions and event triggers.
- Multi-region deployments and disaster recovery.
- Cost management, tagging, and budgeting.
- IAM, security groups, and policy management.
- Observability in cloud environments.
