# API Design and Contracts

This module teaches how to design stable, predictable APIs and their contracts.

Topics covered:
- Resource modeling and naming conventions.
- REST best practices and correct use of HTTP status codes.
- Pagination, filtering, sorting, and sparse fieldsets.
- Idempotency and safe retry patterns.
- Error formats, validation rules, and user-friendly responses.
- Versioning strategies and compatibility policies.
- Authentication and authorization integration.
- Rate limiting, quotas, and abuse prevention.
- OpenAPI/Swagger documentation and JSON Schema.
- gRPC and protobuf basics.
