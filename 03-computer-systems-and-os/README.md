# Computer Systems and Operating Systems

This module explains how software interacts with the OS and hardware, which is
critical for performance and reliability.

Topics covered:
- Processes vs threads and scheduling fundamentals.
- Concurrency primitives: mutexes, semaphores, deadlocks.
- Memory management: stack/heap, virtual memory, paging.
- File systems, storage, buffering, and I/O basics.
- System calls and user space vs kernel space.
- I/O models: blocking, non-blocking, and async.
- CPU caches, context switching, and performance implications.
- Containers and virtualization concepts.
