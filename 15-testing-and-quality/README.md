# Testing and Quality

This module covers correctness and maintainability practices. Each subtopic
includes key concepts, a real-world example, and a diagram.

## Progression expectations

| Level | Outcomes |
| --- | --- |
| Beginner | Write unit tests and use test doubles. |
| Intermediate | Build integration and end-to-end suites. |
| Senior | Establish contract testing and coverage strategy. |
| Principal | Define quality gates and risk-based testing. |

## How to use this module
- Start with unit tests and expand to integration and contracts.
- Produce a test strategy or checklist per subtopic.
