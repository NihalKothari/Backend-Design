# Caching and Performance

This module teaches how to optimize latency and throughput in backend systems.

Topics covered:
- Cache layers: client, CDN, edge, app, database.
- Cache strategies: TTL, write-through, write-back, cache-aside.
- Invalidation patterns and cache stampede prevention.
- Hot vs cold data, eviction policies (LRU, LFU).
- Profiling and tracing for bottlenecks.
- N+1 query patterns, indexing, query optimization.
- Connection pooling and resource limits.
- Async processing and batching.
- Load testing and performance budgets.
