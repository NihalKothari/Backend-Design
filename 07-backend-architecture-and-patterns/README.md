# Backend Architecture and Patterns

This module covers architectural styles and patterns used to build maintainable
backend systems.

Topics covered:
- Monolith vs microservices vs modular monoliths.
- Layered architecture, clean/hexagonal architecture.
- Dependency inversion and dependency injection.
- Domain-driven design building blocks and boundaries.
- CQRS and event sourcing patterns.
- Integration styles: synchronous vs asynchronous.
- API gateway, BFF, and service mesh basics.
- Data ownership, service boundaries, and contracts.
- Scaling strategies and architecture tradeoffs.
