# Backend Architecture and Patterns

This module covers architecture styles and patterns for maintainable backend
systems. Each subtopic includes key concepts, a real-world example, and a
diagram.

## Progression expectations

| Level | Outcomes |
| --- | --- |
| Beginner | Understand monoliths, layers, and architecture terms. |
| Intermediate | Apply clean architecture and DI concepts. |
| Senior | Define boundaries and integration patterns. |
| Principal | Drive reference architectures and alignment. |

## How to use this module
- Start with architecture styles and move into boundaries and patterns.
- Produce a diagram or ADR per subtopic.
