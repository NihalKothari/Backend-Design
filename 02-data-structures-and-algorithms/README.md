# Data Structures and Algorithms

This module focuses on the algorithmic thinking required for efficient backend
systems and problem solving.

Topics covered:
- Big O notation, time/space complexity, amortized analysis.
- Arrays, linked lists, stacks, queues, hash maps/sets.
- Trees: BST, balanced trees, heaps, tries.
- Graphs: representations, BFS/DFS, shortest path algorithms.
- Sorting and searching algorithms and tradeoffs.
- Recursion, backtracking, divide and conquer patterns.
- Dynamic programming and greedy techniques.
- String algorithms and basic bit manipulation.
