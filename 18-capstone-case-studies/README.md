# Capstone Case Studies

This module applies the full curriculum to realistic system design problems.

Topics covered:
- End-to-end system design for common domains:
  - Ecommerce platforms
  - Social feeds
  - Chat and messaging
  - Payments and billing
  - Analytics pipelines
- Requirements gathering and non-functional requirements.
- Architecture diagrams and component breakdowns.
- Data modeling and API surface design.
- Scaling and failure handling strategies.
- Migration plans and evolution over time.
- Tradeoff analysis and alternative approaches.
