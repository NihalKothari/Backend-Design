# Distributed Systems and System Design

This module provides concepts and techniques for scalable, fault-tolerant
systems. Each subtopic includes key concepts, a real-world example, and a
diagram.

## Progression expectations

| Level | Outcomes |
| --- | --- |
| Beginner | Understand CAP and basic replication concepts. |
| Intermediate | Apply sharding and service discovery patterns. |
| Senior | Design for retries, backoff, and failure isolation. |
| Principal | Lead design reviews and set consistency targets. |

## How to use this module
- Start with consistency and replication basics.
- Create a design note per subtopic.
