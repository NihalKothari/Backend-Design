# Distributed Systems and System Design

This module provides the concepts and techniques needed to design scalable,
fault-tolerant systems.

Topics covered:
- CAP theorem and consistency models.
- Replication strategies and leader/follower setups.
- Consensus and leader election basics.
- Sharding and partitioning techniques.
- Service discovery and coordination.
- Idempotency, retries, timeouts, and backoff.
- Distributed transactions and saga patterns.
- Rate limiting, throttling, and backpressure.
- Designing for scalability, failure, and resilience.
- System design case studies and tradeoff analysis.
