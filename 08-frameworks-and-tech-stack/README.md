# Frameworks and Tech Stack

This module helps you choose and use frameworks, runtimes, and tooling to build
production services.

Topics covered:
- Selecting language/runtime (Go, Java, Node, Python, etc.).
- Web frameworks: routing, middleware, dependency injection.
- Configuration management and environment handling.
- Logging, structured logs, and log sinks.
- ORM vs query builders and migration tools.
- Background jobs and scheduling.
- Build systems, packaging, and dependency management.
- Containerization basics and local development workflows.
- Evaluating stack tradeoffs: performance, ecosystem, maintainability.
